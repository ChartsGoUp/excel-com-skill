# 05 — QA Checklist

Use this file as the mandatory pre-delivery checklist.

---

# A. Universal QA

## Source fidelity
- [ ] No requested content was omitted.
- [ ] No unrequested factual changes were made.
- [ ] No values changed unless intended.
- [ ] No dates changed unless intended.
- [ ] No entity names changed unless intended.
- [ ] No formulas were replaced by values unless intended.
- [ ] No unsupported assumptions were introduced.

## Usability
- [ ] The file is easy to navigate.
- [ ] The hierarchy is obvious.
- [ ] Important outputs are easy to find.
- [ ] Labels are readable.
- [ ] No important content is clipped or hidden.
- [ ] No decorative element distracts from information.

## Final verification
- [ ] The final saved artifact was checked, not only the editing script.
- [ ] The delivered file is the latest validated version.
- [ ] The filename is clear.
- [ ] Any unresolved limitation is disclosed.

---

# B. DOCX QA

## Typography
- [ ] Arial used unless template requires otherwise.
- [ ] Body text size is consistent.
- [ ] Heading hierarchy is consistent.
- [ ] No stray fonts or font sizes.

## Lists
- [ ] Bullets are true Word bullets.
- [ ] Numbering is true Word numbering.
- [ ] Indentation is consistent.

## Tables
- [ ] Tables fit within margins.
- [ ] Header rows repeat where needed.
- [ ] Rows do not split unnecessarily.
- [ ] Text is readable.
- [ ] Borders and fills are restrained.
- [ ] Column widths make sense.

## Pagination
- [ ] No accidental blank pages.
- [ ] No heading-only pages.
- [ ] No orphan headings.
- [ ] No clipped text.
- [ ] Page breaks are deliberate.
- [ ] Headers/footers are correct.
- [ ] Page numbering is correct.

## Visual review
- [ ] Every page was visually inspected where possible.

---

# C. XLSX QA

## Integrity
- [ ] Workbook opens without repair warning.
- [ ] No `#REF!`.
- [ ] No `#VALUE!`.
- [ ] No `#DIV/0!`.
- [ ] No `#NAME?`.
- [ ] No unintended `#N/A`.
- [ ] No unintended external links.
- [ ] Formula populations are complete.
- [ ] Equivalent rows/columns use consistent formulas.

## Formatting
- [ ] Arial used unless template requires otherwise.
- [ ] Number formats are consistent.
- [ ] Negatives/zeros follow conventions.
- [ ] Hardcodes/formulas follow color conventions where applicable.
- [ ] Tab colors are consistent.
- [ ] Gridline treatment is deliberate.
- [ ] Column widths are readable.
- [ ] Row heights are readable.
- [ ] No random borders.
- [ ] No clipped labels.
- [ ] No awkward wrapping.

## Navigation
- [ ] Sheet order is logical.
- [ ] Freeze panes are useful.
- [ ] Active sheet/cell is sensible.
- [ ] Zoom is sensible.
- [ ] Hidden content is intentional.

## Printing
- [ ] Print area is appropriate where relevant.
- [ ] Orientation is appropriate.
- [ ] Scaling is reasonable.
- [ ] Repeated print headers are set where needed.

## Financial/accounting checks
- [ ] Roll-forwards reconcile.
- [ ] Statements balance where applicable.
- [ ] Sources = uses where applicable.
- [ ] Opening + movements = closing where applicable.
- [ ] No unexplained residual differences.

## Visual review
- [ ] Important sheets/ranges were visually inspected where possible.
