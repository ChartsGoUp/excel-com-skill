# 01 — DOCX Rules

## 1. Default typography

Unless an approved template states otherwise:

- Primary font: **Arial**
- Body text: **10 pt**
- Table text: **9–10 pt**
- Footnotes / minor metadata: **8–9 pt**
- Use bold for hierarchy, not decoration.
- Use italics sparingly.

Do not introduce Calibri, Aptos, Times New Roman, or mixed fonts unless the source/template requires them.

---

## 2. Heading hierarchy

Use native Word styles.

Default hierarchy:

- Title: 18–20 pt, bold
- Heading 1: 13–14 pt, bold
- Heading 2: 11–12 pt, bold
- Heading 3: 10–11 pt, bold
- Body: 10 pt

Requirements:
- Keep heading styles visually consistent.
- Do not use color alone to indicate hierarchy.
- Do not create a page that contains only a heading unless intentional.
- Keep headings with the first substantive paragraph/table that follows them.
- Number headings only when the document structure benefits from numbering.

---

## 3. Paragraphs

Default:
- Left aligned
- Short paragraphs where practical
- Consistent paragraph spacing
- Avoid blank paragraphs used only to create space

Use spacing controls instead of repeated empty lines.

Recommended body spacing:
- 0–2 pt before
- 4–6 pt after
- approximately 1.0–1.1 line spacing

---

## 4. Bullets and numbering

Use real Word list formatting.

Do not:
- type bullet characters manually,
- use hyphens as fake bullets,
- create inconsistent hanging indents,
- mix numbering systems accidentally.

Bullets should:
- align consistently,
- use the same indentation level for equivalent content,
- use parallel grammatical structure where possible.

---

## 5. Tables

Tables must prioritize readability.

Default:
- Arial 9–10
- restrained header shading
- strong header contrast
- minimal borders
- consistent cell padding
- top-aligned cell content
- sensible column widths

Requirements:
- Repeat header rows on multipage tables.
- Prevent row splitting when practical.
- Do not allow table content to clip outside margins.
- Keep tables on one page where practical, especially short key tables.
- For long tables, allow clean continuation across pages.
- Do not shrink fonts excessively just to force a table onto one page.
- Avoid unnecessary vertical and horizontal gridlines.
- Use alignment and spacing before adding borders.

---

## 6. Page layout

Default:
- Standard portrait orientation unless content requires landscape.
- Consistent margins.
- Avoid large unused areas.
- Avoid accidental nearly blank pages.
- Keep section starts deliberate.

When tables require landscape:
- Use a separate section if needed.
- Preserve header/footer behavior.
- Return to portrait afterward if appropriate.

---

## 7. Headers and footers

Use only useful information.

Typical header:
- company / department / document class

Typical footer:
- date,
- confidentiality label if applicable,
- page number,
- document status/version if needed.

Do not overcrowd headers or footers.

---

## 8. Page breaks

Use intentional page breaks.

Avoid:
- repeated blank paragraphs,
- manual breaks that strand headings,
- unnecessary section breaks,
- page-break patterns that create large empty spaces.

Use:
- keep-with-next,
- keep-lines-together,
- table row controls,
- paragraph spacing,
before manual page breaks.

---

## 9. Cover pages

Do not add a cover page unless:
- requested,
- present in the approved template,
- or clearly appropriate for the artifact.

For operational manuals and reports, a strong first-page title area can be preferable to a decorative cover page.

---

## 10. Dense documents

For dense remediation plans, manuals, or reports:
- make labels easy to scan,
- visually separate status, issue, action, owner, dependency, output, and pass criteria,
- use compact formatting,
- avoid turning every paragraph into a colored box,
- keep repeated structures consistent.

---

## 11. Content preservation

For formatting-only tasks:
- paragraph wording must remain unchanged,
- table text must remain unchanged,
- numbers must remain unchanged,
- section ordering must remain unchanged unless the user requests structural editing.

If content is reorganized, verify that no text was dropped.

---

## 12. Final DOCX QA

Before delivery:
- inspect every page,
- inspect every table,
- confirm fonts,
- confirm headings,
- confirm bullets,
- confirm margins,
- confirm page numbers,
- confirm no clipping,
- confirm no unintended blank pages,
- confirm no heading-only pages,
- confirm all substantive text remains.
